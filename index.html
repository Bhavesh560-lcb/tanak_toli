Firebase સેટઅપ

આ ફક્ત એક જ વાર કરવાનું છે. પછી બધા કર્મચારી અલગ અલગ ફોનથી એક જ ડેટા જોઈ-ભરી શકશે.

  1. પ્રોજેક્ટ બનાવો: console.firebase.google.com ખોલો → Create a project → નામ આપો (દા.ત. tanak-toli) → Google Analytics બંધ રાખો → Create project.
  2. લોગિન ચાલુ કરો: ડાબી બાજુના મેનુમાં Security → Authentication (મોબાઇલમાં મેનુ ☰ માં છુપાયેલું હોય છે) → Get started → ઉપર Sign-in method ટેબ → Email/Password → પહેલી સ્વિચ Enable ચાલુ કરો (બીજી "Email link" બંધ રાખો) → Save.
  3. ડેટાબેઝ બનાવો: ડાબી બાજુ Databases & Storage → Firestore → Create database → Edition પૂછે તો Standard → લોકેશન asia-south1 (Mumbai) → Production mode → Create.
  4. સુરક્ષા નિયમો (Rules): Firestore માં ઉપર Rules ટેબ ખોલો → ત્યાં લખેલું બધું કાઢી નાખી નીચેના Rules પેસ્ટ કરો → Publish. 
    
        
      
    5. 
      
  5. Config કૉપી કરો: ઉપર ડાબે ⚙ → Project settings → નીચે Your apps માં </> (Web) આઇકન → કોઈ પણ નામ આપી Register app → જે const firebaseConfig = { ... } દેખાય તે આખું કૉપી કરી નીચે પેસ્ટ કરો.
